ZaMaGui — яркая версия / полный визуальный релиз v7 (01.11.2026)

1. Создайте резервную копию текущего public_html (включая .htaccess и приватные настройки вне каталога).
2. Установите новый ZIP в чистый public_html либо на тестовый поддомен.
3. Проверьте /, /en/, /ru/, Growth, Kids, AI, Guild, Marketplace, Capital.
4. Переключите светлую/тёмную тему; карточки остаются яркими, белые зубы и одежда не затемняются фильтрами.
5. Проверьте формы: доставка сообщений требует рабочей конфигурации API/CRM.
6. Пройдите приемочные тесты на вашем реальном хостинге перед публикацией.

Изменения: переэкспорт иллюстраций карточек, полная изоляция текста и изображений через CSS Grid, новые иллюстрации Marketplace/Capital без встроенных обрывков текста и прямоугольных краёв, обновлённые иллюстрации для направлений, отключены фильтры dark-mode. Все языковые страницы используют общие CSS и ресурсы.

Файлы HTML разделены по / (UA), /en/ (EN), /ru/ (RU).
Реальные реквизиты CRM/почты и платежей не включены.
